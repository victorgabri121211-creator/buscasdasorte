# BuscasDasorte

Painel de consultas

## Estrutura
```
BuscasDasorte/
├── components/            Partes HTML reutilizáveis
├── images/                Imagens e ícones
├── layouts/               Template base
├── pages/index.html       Página principal
├── scripts/               JavaScript modular
└── styles/                CSS por módulo
```

## Como usar
Abra `pages/index.html` no navegador.

## Admin
Configure a chave da API pelo menu lateral após o primeiro login.
